This guide walks you through configuring Mirra Concierge for your Shopify store. You will choose which styling modes to activate, decide where customers see Concierge, set audience targeting, and apply your brand styling. The fastest path is PDP-only deployment, which requires no Try at Home or Returns setup.

<Steps>
  <Step title="Choose your Concierge modes">
    Open the Concierge settings in your Mirra dashboard.

    Select one or more modes to activate:

    - Virtual Styling Call
    - In-Boutique Appointment
    - Styling Video
    - Styling Notes

    You can start with a single mode and add others later. There is no requirement to enable all four.
  </Step>
  <Step title="Select where to show Concierge">
    Decide which customer touchpoints will display your active Concierge modes:

    - **PDP only**: the Concierge call-to-action appears next to the buy button on applicable product pages. This is the fastest deployment path and does not require Mirra Try at Home or Returns.
    - **Try at Home portal**: customers see styling support while deciding what to keep during their trial.
    - **Returns portal**: a last-chance styling check-in is surfaced before a return is finalised.
    - **Both portals**: full coverage across the customer lifecycle.

    Toggle the touchpoints you want in the Mirra dashboard. You can change these at any time.
  </Step>
  <Step title="Configure boutique locations (if applicable)">
    If you activated In-Boutique Appointments, add your store locations and set booking availability:

    1. Go to Concierge → Locations.
    2. Add each boutique address and time zone.
    3. Set available time slots per location (for example, Tuesday to Saturday, 10:00 to 18:00).
    4. Assign staff members or stylist roles who receive booking notifications.

    Mirra will automatically detect and display the nearest boutique to each customer based on their location.
  </Step>
  <Step title="Set audience rules">
    Control which customers and products see Concierge using audience filters:

    - **By product**: include or exclude specific SKUs or collections
    - **By order value**: only show Concierge on orders above a minimum threshold (for example, \$150 for Virtual Styling Calls)
    - **By customer group**: target VIP segments, first-time buyers, or repeat customers
    - **By collection**: limit Concierge to seasonal drops or high-margin categories

    You can create multiple rules and stack them. For example, you might show In-Boutique Appointments only to VIP customers browsing eveningwear with an order value over \$300.
  </Step>
  <Step title="Apply branding and look and feel">
    Match the Concierge interface to your store identity:

    1. Upload your brand logo and select your primary brand colour.
    2. Choose tone settings for automated messages and note templates.
    3. Preview the Concierge CTA on a test PDP to confirm alignment.

    These settings apply to all touchpoints (PDP, Try at Home portal, and Returns portal) for a consistent customer experience.
  </Step>
  <Step title="Publish and monitor">
    Save your configuration and set Concierge to live. Use the Mirra dashboard to monitor:

    - Booking volume and no-show rates for calls and appointments
    - Video views and completion rates
    - Note engagement and click-through on complete-the-look prompts
    - Revenue attributed back to each Concierge interaction

    Adjust your mode mix and audience rules based on early performance data.
  </Step>
</Steps>

## Quick-start recommendation

<Note>
  If you are not yet using Mirra Try at Home or Mirra Returns, start with PDP-only deployment. This gets styling support live on your store within minutes and does not require any additional checkout or portal configuration.
</Note>

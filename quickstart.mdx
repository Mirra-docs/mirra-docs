Get from install to a working try order. First-run stores land on **Welcome to Try with Mirra** and can set up try-before-you-buy in about 15 minutes.

## Prerequisites

- A Shopify store you can install apps on (a development store is fine)
- Staff access to Shopify Admin
- A product you can mark as try-eligible

Click-by-click Shopify articles also live in [Getting started](https://helpcenter.trywithmirra.com/knowledge-base/getting-started).

## Install and go live

<Steps>
  <Step title="Install Try with Mirra">
    Open the [Mirra app listing](https://apps.shopify.com/try-with-mirra) and click **Add app**. Approve the requested access so Mirra can create try orders, manage returns, and send notifications.
  </Step>
  <Step title="Open onboarding">
    In the Mirra app, go to **Onboarding**. Complete:

    1. **Turn On App Embed** — enable **Try with Mirra** in the theme editor
    2. **Add Button to Product Pages** — add the **Try with Mirra Button** on product templates
    3. **Select Settings & Preferences** — choose try products, trial days, and return method

    Until you click **Go Live**, the app stays in **Preview mode** and is not live on your storefront. If you see **Your Shop's theme is out of date**, the theme is Shopify 1.0 — click **Contact Support** before you go live.
  </Step>
  <Step title="Choose products and trial days">
    In **Settings**, under **Manage Try Products**, select the products or collections shoppers can try. Set **Trial days** — the window starts when the order is **delivered**, not at checkout.
  </Step>
  <Step title="Place a test try order">
    On the storefront, add a try-eligible product with the try button (default label **Try Before You Buy**) and complete checkout as a test customer. Fulfill the order, then mark it delivered so the trial clock can start.
  </Step>
  <Step title="Open the customer portal">
    Use the portal link from the delivered-order email, or copy it from **Try Orders**. Keep one item and return another to confirm keep/return and payout options.
  </Step>
  <Step title="Go live">
    When you are ready for shoppers, click **Go Live** in onboarding. The sidebar shows **App Live**.
  </Step>
</Steps>

<Check>
  You should see the test order on **Try Orders** with line-level try / keep / return state, and the shopper should be able to finish the decision in the customer portal.
</Check>

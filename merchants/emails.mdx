Open **Emails** in the merchant dashboard (**Settings → Emails**, or **Email appearance → Open Emails** from Concierge **Communications**). This page sets shared appearance for **purchased return** emails and **concierge** emails. Try complete-order emails stay Mirra-branded.

## Layout

Pick a layout:

| Layout | Look |
| --- | --- |
| **Classic** | Bold headline and a colour bar footer |
| **Minimal** | Quieter type with links under the sign-off |
| **Editorial** | Serif type, cream page, and a brand colour rule |
| **Bold** | Logo on a CTA-coloured header band |
| **Framed** | Compact bordered card with a tight headline |

## Header logo

**Upload logo** or **Replace logo** — PNG, JPG, or SVG. This is separate from the customer portal logo. Set **Alignment**: **Left**, **Centre**, or **Right**.

## Colours

| Field | Where it applies |
| --- | --- |
| **CTA button** / **CTA text** | Concierge emails and the **Bold** header band |
| **Footer background** / **Footer text** | The **Classic** footer bar. Other layouts use a quieter text footer |

## Sign-off and inbox

| Field | What it does |
| --- | --- |
| **Closing** | Purchased emails default to **Thanks** |
| **Team name** | Defaults to the shop name |
| **From name** | Inbox display name on purchased return emails |
| **Footer help text** | Purchased return and concierge emails. Leave blank for the default help line |

## Footer links

Optional **FAQ URL** and **Privacy URL**. Leave a field blank to hide that link.

## Preview

**Purchased email preview** shows **From** and **Subject**. Tabs: **Label ready**, **Return received**, and **Post reminder**.

Save when you finish. Click-through links in the preview should open (mailto and shop URLs).

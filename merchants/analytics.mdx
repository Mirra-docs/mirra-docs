Open **Analytics** in the Mirra app. Subtitle: **Get insights into your store's performance.**

Pick a date range: All time, Today, Yesterday, Last 7 / 30 / 90 / 365 days.

Help Center: [Analytics Dashboard](https://helpcenter.trywithmirra.com/knowledge-base/getting-started).

## What you can see

| Card | Shows |
| --- | --- |
| Average order value | Try orders vs buy orders |
| **Total Mirra Customers** | **Total Customers** and **First-Time Customers** |
| **Total Discounts** | Discount totals on try vs buy |
| **Mirra Revenue (After returns)** | Revenue from try orders after returns |
| **Total Mirra Orders** | **Placed Orders** and **Completed Orders** |
| Revenue potential | Upside on try volume |
| **Total Mirra vs. Buy orders (Placed)** | Mix of try and buy |
| **Top Returned Products** | Frequently returned items |
| **Purchased Products** | Items shoppers kept |
| **Return Reasons** | Reasons shoppers selected in the portal |
| **Converted try orders** | Orders with at least one kept item vs returns |

You can export kept/returned order CSVs from this page when the export control is available.

<Note>
  **Exports** appears in the app nav only if exports are enabled for your shop. There you pick a month and download the CSV types your store is allowed to use.
</Note>

**Try Orders** is the order inbox in the Mirra app. Home (`/`) opens this list once your shop is live.

Help Center: [Mirra Order Dashboard](https://helpcenter.trywithmirra.com/knowledge-base/merchant-guides).

## Find an order

Tabs: **To Review** · **All** · **Open** · **Return In Progress** · **Closed**.

Columns include **Order**, **Date**, **Customer**, **Total**, **Items**, **Payment Due**, **Payment status**, **Returns**, and **Restock**. Use **Edit Columns** to show **Fulfillment**, **Delivery**, or **Amount Due**.

Return badges you may see: **No Return**, **Return Initiated**, **Return Overdue**, **Open**, **Upload Return Label**, **In Transit**, **Delivered**.

<Tip>
  On a Shopify order details page, pin the **Mirra Returns** block so staff see Mirra return status without opening the app. If there are no Mirra returns, the block shows **No Mirra returns**.
</Tip>

## Actions on one order

Select an order, then **More actions**:

| Action | Use it to |
| --- | --- |
| **Copy Customer Portal URL** | Send the shopper their portal link. They can also open **Open Mirra Customer Portal** from the Shopify order status page. |
| **Create New Order Link** | Build a checkout link with those products |
| **Manage Return** | Add carrier and tracking (**Add Tracking**, **Send to customer**) |
| **Generate Return Label** | Create a prepaid label when your return method supports it |
| **Mark Return as Delivered** | Mark returned items received |
| **Manage Trial Items** / **Review Trial Items** | **Move to Trial** or **Remove from Trial** |
| **Set Payment Due Date** | Change the due date |
| **Authorize Payment** | Retry authorization |
| **Capture Payment** | Capture now |
| **Void Authorization** | Release the hold |
| **Mark Order as Complete** | Stop Mirra automation on this order |

Click **Upload Return Label** on a badge to open **Add Tracking**. Click an **Available** restock badge to open **Restock Items**.

<Warning>
  **Mark Order as Complete** stops Mirra from continuing keep/return automation on that order. Use it when staff have already settled the order outside the usual portal flow.
</Warning>

Use **Set Payment Due Date** when a shopper needs more time. In the last 24 hours they may also see **Request time extension** in the portal (adds 48 hours) and get an SMS with the same option.

## Authorization and fulfillment

Try orders should show as **Authorized** in Shopify, with the **Try with Mirra** tag. Fulfil and ship those as usual — do not wait for a capture.

If the hold cannot be placed:

- Shopify status is **On hold**, with a note such as **This order is awaiting payment authorization. Please do not fulfill until payment is authorized.**
- The tag **Failed to authorize payment** is added
- Mirra emails the shopper and retries for about **12 hours**
- If a retry succeeds, the hold and tag are cleared and the order can ship
- If it still fails, the order is cancelled when **Cancel order when authorization fails** is on in [Settings → Advanced](/merchants/settings)

<Warning>
  Do not fulfil orders tagged **Failed to authorize payment**, marked **On hold**, or with payment **Pending** or **Expired**. Your warehouse should skip those until the order is **Authorized** again — or cancelled.
</Warning>

Help Center: [Failed authorization recovery](https://helpcenter.trywithmirra.com/knowledge-base/failed-authorization-recovery) and [Warehouse and fulfilment](https://helpcenter.trywithmirra.com/knowledge-base/warehouse-and-fulfilment-integration-guide).

## Missing or damaged returns

If a shopper does not send an item back, or it comes back unsellable, you can add a charge on the Shopify order (edit the order and collect on the stored card) instead of opening a separate invoice. Write the reason on the order — for example item not returned, or damaged in trial.

Help Center: [Manual charges for returns](https://helpcenter.trywithmirra.com/knowledge-base/manual-charges-for-returns-missing-or-damaged-items).

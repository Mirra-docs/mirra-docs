Return shipping is set per country in the Mirra app: **Settings → Returns**, under **Return labels / management**.

The Returns Dashboard shows these methods read-only. Change them here, then **Save Changes**.

## Choose a method per country

**Select how you will manage returns**:

| Option | Shopper experience |
| --- | --- |
| **Send return label via email** | Prepaid label emailed after they submit |
| **Include return label with the outgoing order** | They use the label already in the parcel |
| **Allow customers to handle their own returns** | They buy postage and use your **Return address** |
| **Return in-store** | Drop off at a store location |
| **Use eParcel account to generate return labels** | Australia Post labels (connect on **Integrations**) |
| **Use Starshipit API to generate return labels** | Starshipit carriers |
| **Use Royal Mail API to generate return labels** | Royal Mail labels |
| **Use Shippo API to generate return labels (USA only)** | Shippo labels |
| **Bring your own return label (customer provides tracking)** | Shopper enters tracking number and carrier |

Also set:

- **Which email should receive return requests?**
- **Return address**
- **Return instructions** (shown in the portal after submit)
- **Restocking Fee Discount** when it applies
- Store locations for in-store returns

<Note>
  Connect Australia Post, Starshipit, Royal Mail, or Shippo on **Integrations** before you select those label methods. See [Integrations](/merchants/integrations).
</Note>

## What shoppers pick in the portal

Depending on your method, the portal offers titles such as **Download label now**, **Self return**, **Drop off at a store**, **Email return instructions**, **Use shipping label provided by store**, or **I have my own return label**.

After they submit, they see print / pack / post steps, a copyable return address, or a waiting page while the label generates. Default copy asks them to post within **3 days**.

Staff can still **Generate Return Label** or **Manage Return** from [Try Orders](/merchants/try-orders) when a label needs to be created or tracking added by hand.

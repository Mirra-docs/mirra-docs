When a shopper returns try items — or purchased items Mirra manages — you choose which **payouts** they can pick and how staff process the return.

Open **Returns Dashboard** from the Mirra app nav. Policies live under **Settings → Return Policies**.

## Payout options

| Payout | Shopper receives |
| --- | --- |
| **Refund to original payment** | Money back on the original payment method |
| **Store credit** | Balance on their Shopify customer account |
| **Gift card** | A one-time gift card code (email + portal) |
| **Exchange** | A replacement checkout, when your policy allows it |

<Info>
  Store credit uses Shopify customer accounts (new customer accounts). Gift cards work at standard checkout and do not require that setup. Shoppers who paid the original order with store credit or a gift card do not see those as refund options in the portal.
</Info>

## Configure policies

<Steps>
  <Step title="Open return policies">
    In the Returns Dashboard go to **Settings → Return Policies**. Filter **All policies**, **Purchased returns**, or **Try before you buy**. Click **Save all policies** when you finish.
  </Step>
  <Step title="Edit policy details">
    Set **Policy name**, **Countries**, and **Returns allowed** (**Eligible** or **No returns**). Set **Return window (days)** and **Window starts from**: fulfillment date, delivery date, or order placed date.
  </Step>
  <Step title="Set eligibility rules">
    Optionally match **Product tags**, **Order tags**, **Line item unit price**, or **Compare-at price**. Choose **All conditions must match (AND)** or **Any one condition can match (OR)**.
  </Step>
  <Step title="Choose payout types">
    Under **Customer refund options**, turn on **Refund to original payment**, **Store credit**, and/or **Gift card**. For credit or gift cards you can set **Automatically issue store credit** / **Automatically issue gift card** and a bonus percent.
  </Step>
  <Step title="Configure exchanges">
    Turn on **Offer exchange for items matching this policy**. Set the **Exchange window** (**Edit settings**) — that is the deadline shoppers see in the portal. Choose when to **Process replacement**: when the return is approved, in transit, or delivered.

    Optional:

    - **Use same-order exchanges** — reserve the replacement on the original Shopify order and charge or refund only the price difference
    - **Waive the return fee for exchange-only returns**
    - **Also update outstanding orders** — when you turn exchange on or change the window, apply it to eligible orders already placed
  </Step>
  <Step title="Set approval">
    **Auto-approve purchased returns** — when off, purchased returns that match this policy wait for a manual **Approve** in the dashboard before the shopper can continue.
  </Step>
  <Step title="Re-authorize the app if prompted">
    Store credit, gift cards, and exchanges need extra Shopify scopes. If Shopify asks you to update permissions, approve them before testing. You can also accept **Optional permissions** on **Integrations**.
  </Step>
</Steps>

<Tip>
  Auto-approve returns and auto-issue credit are separate. Approving a return does not issue store credit unless **Automatically issue store credit** is on for that payout type.
</Tip>

Portal extras (sheet on Return Policies):

- **Return item photos**: Don't ask · Optional · Required
- **Default restock location**
- **Restock items by default** — **Enable restock by default** starts **Restock items** checked when you resolve a return. Turn it off if you restock inventory outside Shopify. You can still enable restock on one return. The primary action says **Refund & restock** when restock is on, or **Refund only** when it is off.

Try-order **return shipping** methods stay in Shopify Admin **Settings**. The dashboard shows them read-only. See [Return shipping](/merchants/return-shipping).

## Process a return

On **Returns**, tabs are **Needs action** · **In progress** · **Closed**. Filter **All**, **Trial**, **Regular**, or **Mixed**. Search by RMA, order, or customer.

Click **Open Returns Portal**, enter an order number, then open or copy the customer portal link for that order.

Open a return and:

| Action | What happens |
| --- | --- |
| **Approve** | Optional notify customer. May auto-issue store credit or gift card |
| **Decline return** | Requires a **Decline reason** and note |
| **Receive return** | Received via post, in person, or manual |
| **Issue store credit** / **Issue gift card** | Manual payout if auto-issue is off |
| **Resolve return** / **Refund and close** | Refund to original payment, optional **Refund shipping**, restock, **Notify customer** |
| **Cancel return** | Stop the return |

**Advanced** on resolve lets you close with **no refund owed**.

## Shopify setup for store credit

1. **Settings → Customer accounts** — use **new customer accounts**.
2. Enable **store credit** in Shopify.
3. Make sure shoppers can log in on the storefront and at checkout.

Gift cards skip this list: the shopper gets a code they can apply at checkout.

<Warning>
  Gift card creation through Shopify can be limited on some plans. Test on a development store before promising the option to customers.
</Warning>

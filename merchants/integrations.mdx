Open **Integrations** in the Mirra app. Connect the tools you use for labels and extra Shopify access. [Klaviyo](/merchants/klaviyo) and [MCP](/merchants/mcp) have their own pages.

## Optional Shopify permissions

**Optional permissions** — click **Accept** if Shopify asks for extra scopes. You need these for store credit, gift cards, and exchanges. If a payout or exchange control is disabled, grant permissions here, then try again.

## Exchanges

**Exchanges V2** — **Enable Exchanges V2** / **Disable Exchanges V2**. When on, shoppers pick a replacement on your storefront during the [exchange window](/merchants/settings). Also turn on **Offer exchange on try orders** in **Settings → Returns**.

## Return label providers

Connect a provider before you select its method in [Return shipping](/merchants/return-shipping).

| Card | Merchant actions |
| --- | --- |
| **Australia Post** | **Enable Integration** / **Disable Integration** for eParcel return labels |
| **Starshipit** | API key, **Return Addresses**, and carrier (Australia Post, Aramex, UPS, FedEx, USPS, Royal Mail, DHL, and others listed in the form) |
| **Royal Mail** | API for UK return labels |
| **Shippo** | USA labels — **General Settings**, **Default Package Settings**, **Return Addresses** |

## Mirra Store

**Mirra Store** — **View Setup Guide** if you are going live on the Mirra Store app. Follow that guide rather than this page.

<Note>
  Other fulfillment tools you already use (for example your 3PL) are not configured on this screen. Keep those in Shopify or the provider’s own admin.
</Note>

## Revoke AI access

If you have connected AI assistants, **MCP** appears here. **Revoke access** disconnects every AI client for the shop. Staff can reconnect later. Details: [Connect AI assistants](/merchants/mcp).

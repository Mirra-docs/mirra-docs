Use **Discounts**, **Gift Rules**, and **Samples** in the Mirra app to attach offers to try orders. Prefer these when the promotion should survive a partial keep/return.

Help Center: [Discount & Promo Codes for Mirra Orders](https://helpcenter.trywithmirra.com/knowledge-base/merchant-guides).

## Discounts

Open **Discounts**. Click **Create** (or open an existing row to edit). Table columns: **Name**, **Status**, **Type**, **Automatic**, **Code**, **Savings**, **Minimum Kept Items**. You can bulk activate or deactivate.

| Field | What it does |
| --- | --- |
| **Type** | **Fixed Amount Off** or **Buy X Get Y** |
| **Name** | What shoppers see in the customer portal |
| **Status** | **Activate** / **Deactivate** — only active discounts apply |
| **Savings Value** | Flat amount or percent off each try item they **keep** |
| **Code** | Shoppers enter this at checkout. **Generate Code** fills one. Hidden when the discount is automatic or **Buy X Get Y** |
| **Is Automatically Applied** | Apply without a code when the order qualifies. **Buy X Get Y** is always automatic |
| **Minimum Item Requirements** | How many items the shopper must **keep** to get the discount |

<Note>
  **Minimum Item Requirements** is kept items after the trial, not how many try items they put in the cart.
</Note>

## Shopify and third-party discounts

Shoppers enter a Shopify code at the **first** checkout, not in the portal.

| Type | Use on try orders? |
| --- | --- |
| Shopify **percentage off** | Usually yes. Create it as a **product discount**, not an **order discount**, so it does not attach to a restocking fee if they return everything. |
| Shopify **fixed amount off** (for example \$20 off) | Avoid. Shopify splits the amount across lines, so a partial keep leaves an awkward leftover. |
| Shopify **Buy X Get X** | No — it does not split cleanly when they keep only part of the order. Use Mirra **Buy X Get Y** instead. |
| Gift card or voucher at try checkout | No. They must pay with a card. They can apply a gift card later in the [customer portal](/shoppers/customer-portal) when they settle. |
| PayPal, Afterpay, and other buy now, pay later | No. Try checkout needs a saved card. PayPal is hidden on try carts. |
| Third-party discount apps | Test a keep-and-return before you go live. Behaviour varies. |

## Gift rules

Open **Gift Rules**. Click **Create gift rule**.

| Field | What it does |
| --- | --- |
| Gift product | The free (or reduced) item added to the try order |
| **Minimum spend** | Order total that unlocks the gift |
| **Gift item cost** | How much the gift counts as if they keep it |

Shoppers see gift lines in the portal with a **Gift** pill. Portal copy explains that they may need to keep enough of the order to qualify.

## Free samples

Open **Samples**. Click **Add Rule**.

| Field | What it does |
| --- | --- |
| Sample product | The sample variant |
| **Quantity** | How many of that sample |
| **Trigger** | **Global** (any try order) or specific products |

Checkout allows **one free sample item per order**, and only on try-before-you-buy orders.
